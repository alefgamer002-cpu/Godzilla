# Godzilla
Godzilla Run é um jogo inspirado no Dino Offline do Chrome, mas com o Godzilla como personagem principal. Em cada partida, os obstáculos aparecem em posições diferentes, tornando o jogo mais dinâmico. O jogador controla o Godzilla usando as setas do teclado para se mover e pular. Além de desviar dos obstáculos.
